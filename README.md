# Accenture Project — Find Your Place in Tech

A small web app built as part of an Accenture programme project to help users explore tech career paths.

It includes:
- A **homepage** with an “AI advice” form that generates personalised next steps
- A **resources page** with role overviews, salary ranges, and links to learn more
- A **team page** showcasing contributors and what each person worked on

## Demo (Local)

This project runs as:
1) Static frontend pages (HTML/CSS/JS)
2) A small Python Flask API that calls Google Gemini to generate the advice

---

## Features

### ✅ AI Career Advice (Homepage)
Users fill in career info (journey stage, education, work style, tech experience, interests, values) and the app returns **3 clear next steps** generated by Gemini. :contentReference[oaicite:1]{index=1}

### ✅ Career Resources (Resource Page)
Accordion-style role cards with:
- a short role overview
- typical UK salary ranges
- links to external career resources :contentReference[oaicite:2]{index=2}

### ✅ Team Page
Interactive team selector: click a team member avatar to display their experience, achievements, and contributions. :contentReference[oaicite:3]{index=3}
